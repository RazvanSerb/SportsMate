# SportsMate
Aplicația permite utilizatorilor să găsească parteneri pentru jocuri sportive (fotbal, tenis, baschet etc.) în apropiere, în funcție de distanță, nivel și disponibilitate. Funcționalitățile principale vor fi implementate în două variante: una bazată pe modele de proiectare (Strategy, Observer, State, Factory Method, Repository, arhitectură stratificată cu Dependency Injection) și una cu anti-pattern-urile asociate (God Object, Spaghetti Code, polling, abuz de Singleton, Big Ball of Mud). Variantele vor fi comparate prin măsurători de performanță (timp de răspuns, memorie, scalabilitate pentru 10.000–100.000 de utilizatori simulați) și de mentenabilitate (complexitate ciclomatică, cuplare, efortul necesar pentru adăugarea unui sport sau a unui criteriu nou de potrivire).
