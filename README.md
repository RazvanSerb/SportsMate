# SportsMate
Aplicația permite utilizatorilor să găsească parteneri pentru jocuri sportive în apropierea sa, în funcție de disponibilitate. Funcționalitățile vor fi implementate în două variante: una bazată pe șabloane de proiectare și una cu anti-pattern-urile asociate. Variantele vor fi comparate prin măsurători de performanță și de mentenabilitate.
